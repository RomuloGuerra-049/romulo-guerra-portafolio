Resumen

Aplicación web Full Stack que reúne un portafolio profesional, autenticación segura y dos experiencias privadas: un centro de control para administración y un portal independiente para clientes.

Objetivo

Centralizar la presentación profesional, la captación de contactos y la gestión de proyectos en una única plataforma, evitando depender de cambios manuales en el código para las tareas operativas habituales.

Funciones principales

  • Portafolio público responsive con proyectos administrables.
  • Registro, inicio y cierre de sesión con permisos por rol.
  • Panel administrador para usuarios, proyectos, solicitudes y contactos.
  • Portal cliente para seguimiento, nuevas solicitudes y cambios.
  • Publicación de proyectos con imagen almacenada en PostgreSQL.
  • Formulario de contacto persistente y preparado para SMTP.
  • Chat web preparado para automatización mediante n8n y WhatsApp Business.
  • Interfaz disponible en español, inglés e italiano.

Tecnologías y arquitectura

El frontend utiliza HTML semántico, CSS responsive y JavaScript modular sin framework. El backend está construido con Node.js y su servidor HTTP nativo. PostgreSQL ofrece persistencia mediante el paquete pg; dotenv administra configuración por entorno y Nodemailer integra el correo SMTP.

La arquitectura separa rutas HTTP, servicios de dominio, middleware de autenticación, validadores y repositorios. Esta división permite probar la lógica con memoria y utilizar PostgreSQL en ejecución real.

Seguridad

Las contraseñas se protegen con derivación criptográfica y salt individual. Las sesiones utilizan tokens aleatorios guardados únicamente como hash, cookies HttpOnly y comprobaciones de rol en el servidor. La documentación no incluye credenciales, tokens, direcciones privadas ni secretos de infraestructura.

Public documentation · English

Overview

A Full Stack web application combining a professional portfolio, secure authentication and two private experiences: an administration control center and a separate client portal.

Goal

Centralize professional presentation, contact acquisition and project management in a single platform while avoiding manual code changes for routine operational tasks.

Core features

  • Responsive public portfolio with administrable projects.
  • Registration, sign-in and sign-out with role-based permissions.
  • Admin dashboard for users, projects, requests and contacts.
  • Client portal for progress tracking, new requests and changes.
  • Project publishing with images stored in PostgreSQL.
  • Persistent contact form prepared for SMTP delivery.
  • Website chat prepared for n8n and WhatsApp Business automation.
  • Interface support for Spanish, English and Italian.

Technology and architecture

The frontend uses semantic HTML, responsive CSS and modular JavaScript without a framework. The backend is built with Node.js and its native HTTP server. PostgreSQL provides persistence through the pg package; dotenv manages environment configuration and Nodemailer handles SMTP integration.

The architecture separates HTTP routes, domain services, authentication middleware, validators and repositories. This makes it possible to test the logic in memory while using PostgreSQL in the real environment.

Security

Passwords are protected with cryptographic derivation and an individual salt. Sessions use random tokens stored only as hashes, HttpOnly cookies and server-side role checks. This documentation contains no credentials, tokens, private addresses or infrastructure secrets.
